Endpoints
MethodPathPurpose


GET/api/healthLocal service and model status.


GET/api/datasets?q=ADList or filter datasets.


GET/api/datasets/{id}Dataset information and file references.


GET/api/datasets/{id}/schemaColumn descriptions and types.


GET/api/datasets/{id}/readme/{kind}Documents. kind: notes (short file guide), synthetic (how the fake data were made), tracker (matching spreadsheet entry), original, original_section. catalog is a compatibility alias for synthetic. Optional files parameter scopes the short guide to selected fake-data filenames.


GET/api/datasets/{id}/files/{filename}/preview?limit=10Synthetic rows only, maximum 50.


GET/api/datasets/{id}/download/{filename}Approved synthetic CSV or documentation download.


POST/api/chatBody: {"query":"Show IBD","use_llm":true}


POST/api/catalog/reloadReload prepared local files.


Dataset IDs: IBD, MGB_AD, UPMC_AD.
